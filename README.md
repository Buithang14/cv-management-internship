# 📄 Hệ Thống Quản Lý CV (CV Management System)

Hệ thống quản lý CV nội bộ doanh nghiệp hỗ trợ tạo, cập nhật, duyệt CV theo quy trình 2 trạm (Tech Lead & HR) và quản lý phiên bản đa ngôn ngữ (Master-Slave: VI / EN / JA).


## 🛠️ Công Nghệ Sử Dụng

- **Backend**: Java 21, Spring Boot, Spring Data JPA, Spring Security, JJWT (JSON Web Token), MariaDB.
- **Frontend**: React, JavaScript (ES6+), Vite, Tailwind CSS / Ant Design.
- **Khác**: Docker, Git.
